Raccourcis clavier

Envoyer vers l'iPhone

Un fichier .ics est produit à partir des blocs choisis et placé tel quel dans le corps du message. Les identifiants d'événement sont stables : un renvoi met à jour les entrées déjà importées sur l'iPhone au lieu de les dupliquer.

Sur iPhone, l'automatisation Raccourcis lit le corps du courriel, l'enregistre en cadran.ics puis l'ajoute au calendrier — aucun hébergement n'est nécessaire.

Synchronisation GitHub

Le dépôt devient le coffre-fort central de l'emploi du temps : chaque appareil garde une copie locale et la synchronise avec data/schedule.json dans le dépôt indiqué.

Créez le jeton sur github.com → Settings → Developer settings → Fine-grained tokens, limité au dépôt ci-dessus, avec la permission Contents : Read and write uniquement. Il est conservé uniquement dans le navigateur de cet appareil (jamais dans l'export .json, jamais transmis ailleurs qu'à api.github.com).
